To-Do List App

A simple and responsive To-Do List web app built using HTML, css, and JavaScript. This
allows users to add, complete, and delete tasks easily.

Features
 
  1. add new tasks
  2. Mark tasks as completed
  3. Delete individual tasks
  4. Fully responsive design

Click below link to view

    https://devendra-prasad.github.io/todo-list/

Technology used

  1 HTML5
  2 CSS3
  3 JavaScript

How to Run
  open the index.html file in your browser.
